Política de privacidade

Extensão “Integra Vendas para WhatsApp” para o Google Chrome · vigente desde 26/09/2026

A extensão é uma ferramenta de trabalho para vendedores de empresas clientes do Integra Vendas. Ela mostra, ao lado de uma conversa do WhatsApp Web, o cadastro do cliente, preços, estoque e pedidos do Integra Vendas, e ajuda o vendedor a montar orçamentos e lembrar retornos. Ela não envia mensagens: todo texto que prepara vai para a caixa de digitação, e quem aperta “Enviar” é o vendedor.

Com quem os dados são compartilhados

Só com a API do Integra Vendas da empresa em que o vendedor trabalha, que já é a dona do cadastro de clientes, produtos e pedidos. A extensão não tem servidor próprio, não usa ferramentas de análise ou publicidade, não vende dados e não os repassa a terceiros.

As fotos de produto são baixadas dos endereços de imagem que o próprio cadastro do Integra Vendas informa. O botão “Pesquisar fora” abre, numa aba nova e só quando o vendedor clica, uma busca pelo nome da peça no Google ou em sites de fabricantes; nenhum dado do cliente vai nessa busca.

Por quanto tempo

Os dados locais ficam no navegador até o vendedor apagá-los em Ajustes → “Apagar dados”, sair da conta ou remover a extensão. Os dados enviados ao Integra Vendas seguem a política de retenção da empresa contratante.

Segurança

  • Toda comunicação com a API é feita por HTTPS; a extensão recusa endereço sem HTTPS.
  • O token de acesso fica no processo de fundo da extensão e não é exposto à página do WhatsApp.
  • A extensão não carrega código de fora do pacote publicado na Chrome Web Store.

Uso limitado

O uso das informações recebidas pela extensão obedece à Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de uso limitado.
